Rotational grazing: live simulation

Cattle graze one paddock at a time, then move to the next. Every morning someone checks the grass, decides, and acts. Can you keep the grass healthy and the cattle growing all season?

The grazing decision, one day at a time. The move rule sees only the measurements and decides each morning whether the herd stays or moves. Run it on a simulated season, or on your own field records. Click any block for a plain explanation.

Level:

Measure, decide, act, and measure again the next morning. A home thermostat works the same way: it measures, decides, and measures again.

Field records

Every reading is one row: date, paddock, type, value. Enter rows below, paste a CSV, or load a file. The same file format can come straight from the lab's processing pipelines. Press Apply to replay the records through the move rule. The move rule then gives its recommendation for each morning, next to what was actually done.

Clip quadrats for one paddock

Each quadrat becomes one clip row. Dry grams over the frame area convert to kg DM/ha: g / m² x 10. The mean, its standard error, and the 95 percent interval are computed from the rows.

For a pipeline feed: the lab's processing scripts write a CSV in this format to the repository, for example data/field-records.csv, and the page on GitHub Pages loads it by that path. Loading from other sites works only if they allow it. It does not work inside the claude.ai preview.

File format

ColumnMeaning
dateYYYY-MM-DD, or a day number. Use one style for the whole file.
paddock1, 2, 3 ... (P3 also works). Needed for forage mass rows and move rows.
typeclip, uav, rover, map (either platform), plate, visual (forage mass); camera, scale (weight); move (the herd enters this paddock that day); temp (daily mean air temperature, optional)
valueForage mass as paddock mean, or one clip quadrat per row. Weight per animal or herd mean. Empty for move rows.
unitkg/ha or lb/ac; kg or lb; C or F. Blank means kg/ha, kg, C.
animalAnimal ID for camera and scale rows. Blank means the value is a herd mean.
n, sdOptional. For a clip row that is already a mean: number of quadrats and their SD.
roleOptional: pre, mid, post, rest. Blank is inferred from the move rows: on a move day, readings on the paddock left are post and on the paddock entered are pre.
noteFree text, ignored.

The first day needs a move row that says where the herd starts. Rows starting with # are comments. Records are kept in this browser only.

Run every year

Runs the residual and ADG rule and a calendar with the same mean grazing period on every usable year, with the current settings. The spread across years is the range of outcomes this rule would have had.

Compare: calendar versus residual and ADG rule

Runs the full season twice with the current settings and seed. The residual and ADG rule runs first. The calendar then moves on a fixed schedule with the same mean grazing period, so the comparison is fair. Scores use the true state, which the move rules never see.

Compare forage mass sensors

Runs the residual and ADG rule three times on the same seed, once with each forage mass sensor. Weights, weather, and settings are identical.

Sensor error against clips

Each sensor reading is paired with the clip quadrats taken on the same paddock and day. Error is relative to the clip mean. Scatter is shown twice: as measured, and with the clip mean's own sampling error removed, which is the sensor's error alone. Use in simulator replaces that sensor's placeholder error model with the measured bias and scatter.

Apply records that include clips and at least one sensor on the same paddock and day.

Model and farm parameters (file)

One JSON file sets the farm layout (number and area of paddocks), the herd (head count and starting weight), and the model constants, each within a checked range. Use it to save a calibrated setup, share it, and repeat a run exactly. A file starts from the defaults: values it does not list keep their default. A file that breaks a consistency check (for example Tmin < Topt < Tmax) changes nothing.
